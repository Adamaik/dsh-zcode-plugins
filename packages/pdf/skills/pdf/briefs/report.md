# Report brief

Use for reports, reviews, proposals, resumes, cover letters, and any document whose value is its structured argument.

## Structure

1. Open the Markdown source with `#` for the document title and `##` for sections. Go one level deeper only when a section genuinely splits.
2. Lead every section with the finding, then the evidence. Do not make the reader read to the end of a section to learn what it concludes.
3. Give numbers a unit and a period ("12.4 ms p95, June 2026"), and name the source of any figure the user did not supply.
4. Use a table when three or more items share the same fields; use a list when order or priority matters; use prose otherwise.
5. Close with the decision, the owner, or the next action the user asked for.

## Layout

- A4 or Letter, 20 mm margins, 10.5 pt body, 1.5 line height. The renderer's defaults are already in that range; change them only for a stated reason.
- Titles carry the document; sections carry the argument; do not bold body text for emphasis when a heading or a sentence would do.
- Page breaks (`---`) belong before a major section, never inside a table or between a heading and its first paragraph.
- One artifact per request. Do not append an unrelated document to fill a page.

## Check before delivery

- Page count matches the expected section count; no blank trailing page.
- No table crosses a page boundary without a repeated header row.
- Headings are not orphaned at the bottom of a page.
- Every figure cited in the text appears in the document or is marked as external.
